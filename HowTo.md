# <div align="center">Jsonify</div>
## How to download and use Josify
### Installation(Python 3.X required)
First start by downloading jsonify.py by going to /RequestTimeout/Jsonify/src/jsonify.py and downloading jsonify.py from there.

Then drop the Python file somewhere accessible like:
```
C:\jsonify\jsonify.py
```
Then if you see a disgusting looking JSON file, you can open the terminal and run:
```bash
python "C:\jsonify\jsonify.py"
```
And enter the path to the JSON file and Jsonify will output an HTML file at the directory that the terminal was open at.
